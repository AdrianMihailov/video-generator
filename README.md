# Video Generator

A template for building premium vertical motion-design videos with Remotion + React + TypeScript.

## Features

- 1080x1920 vertical format
- 30 FPS
- 4-scene motion design template
- editable config-driven story data
- Remotion preview and render scripts

## Scripts

```bash
npm install
npm run dev
npm run render
```

Rendered output will be saved to:

```text
out/video.mp4
```
